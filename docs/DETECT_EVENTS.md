# 9단계 탐지 연습 사건 계약

\`npm run detect:test\`는 \`src/detect.mjs\`의 \`detect(events)\`에 가상 사건을 전달합니다. 사건에서 사용하는 값은 **세 가지**뿐입니다.

- \`at\`: UTC ISO 8601 시각 (예: \`2026-10-01T00:00:00.000Z\`)
- \`method\`: HTTP 메서드. 정확히 \`GET\`인 사건만 집계합니다.
- \`identity.sub\`: 가명 주체를 구분하는 문자열

예시:

\`\`\`js
{
  at: '2026-10-01T00:00:00.000Z',
  method: 'GET',
  identity: { sub: 'learner_fixture' }
}
\`\`\`

기기 ID, 네트워크, 지역, 판정 결과 또는 메모 본문은 계약에 필요하지 않습니다. 탐지기는 이와 같은 추가 메타데이터를 읽지 않으며, 응답에도 복사하지 않습니다.

## 회수 제안 조건

같은 \`identity.sub\`의 \`GET\` 사건을 시각 순으로 정렬해 모든 이동 10분 구간을 확인합니다. 하나의 10분 구간에 GET이 **120건을 초과**할 때만 회수 제안을 반환합니다. 정확히 120건은 제안하지 않습니다. 시간 간격이 정확히 10분인 두 끝점도 같은 10분 구간에 포함됩니다.

사건 예시 결과:

\`\`\`js
{
  action: 'propose_revocation',
  reasonCode: 'burst_read',
  subject: 'learner_fixture'
}
\`\`\`

기준을 넘는 구간이 없으면 결과는 정확히 \`{ action: 'observe' }\`입니다. 서로 다른 \`identity.sub\`의 사건은 합산하지 않습니다. 여러 주체가 기준을 넘는 경우에는 한계 초과가 먼저 발생한 주체를 반환하며, 동시에 발생하면 주체 문자열의 사전순으로 결정합니다.

이 함수는 가상 회수 제안만 반환합니다. 실제 기기 권한을 회수하지 않으며, 로컬 테스트 통과는 심판 합격이나 운영 엔진 연동 증거가 아닙니다.

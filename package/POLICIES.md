# 검문소·탐지 규칙

| 규칙 | 막는 공격 | 확인 방법 |
|---|---|---|
| device_registered | 미등록 기기 요청 | 가상 판정 테스트 |
| signal_provenance | 누락·불명확한 신호 위장 | 가상 판정 테스트 |
| resource_scope | 허용되지 않은 서비스·HTTP 동작·정확한 경로·경로 템플릿 접근 | 경로 불일치 가상 테스트 |
| instructor_role_required | 학생 계정의 공지 생성·수정·삭제 시도 | 판정기 기본 거부 및 API 구역 역할 검사 |
| unusual_access_context | 비정상 시각·처음 보는 네트워크·대량 열람의 결합 | 복합 이상 가상 테스트 |

브라우저에서 버튼을 숨기는 것만으로 API 접근이 차단됐다고 기록하지 마세요. 최종 API는 로그인 주체, 구역 멤버십, 소유자 및 강사 역할을 다시 확인합니다.

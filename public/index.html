보호 중인 자료실

화면은 서버 API를 통해 학습용 데이터베이스에서 가상 메모를 가져옵니다. 메모 본문은 공개 정적 파일에 포함하지 않습니다.

계정 로그인

Supabase Auth 이메일·비밀번호 로그인을 사용합니다. 로그인하면 계정 이메일과 로그아웃 버튼이 표시됩니다.

보호 안내: 메모 목록과 단건 조회·수정·삭제는 서버에서 검증한 로그인 계정의 소유자 ID를 기준으로 처리합니다. 로그인하지 않은 요청은 거부되며, 브라우저는 로그인 토큰이나 Supabase 키를 직접 다루지 않고 같은 사이트의 서버 API만 호출합니다. 실습에는 가상 자료만 사용하세요.

이 기기 등록 및 승인

설치 표시만으로 기기를 신뢰하지 않습니다. 이 브라우저의 개인키로 요청을 서명하고, 서버에서 승인된 기기만 자료실 API에 접근할 수 있습니다. 개인키는 이 브라우저의 로컬 저장소에 보관됩니다.

로그인 후 이 브라우저를 등록하고 승인하세요.

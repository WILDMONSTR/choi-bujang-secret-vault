BYTE BACK · 3단계 로그인

보호 중인 자료실

화면은 서버 API를 통해 학습용 데이터베이스에서 가상 메모를 가져옵니다. 메모 본문은 공개 정적 파일에 포함하지 않습니다.

계정 로그인

Supabase Auth 이메일·비밀번호 로그인을 사용합니다. 로그인하면 계정 이메일과 로그아웃 버튼이 표시됩니다.

3단계의 알려진 약점: 목록은 로그인 계정의 메모만 보여 주지만, 단건 조회·수정·삭제 API에는 아직 소유자 검사가 없습니다. 다른 로그인 계정이 메모 ID를 알고 있으면 접근할 수 있습니다. 4단계에서 이 문제를 해결하며, 지금은 가상 자료만 사용하세요.

내 가상 메모

로그인한 사용자의 메모를 불러오는 중입니다.
